# Notebook Reproducibility Policy

The command-line scripts are the canonical reproduction path for artifact evaluation:

```bash
make reproduce
make verify
```

The notebooks are explanatory companions. They are designed to be run from the repository root and include markdown descriptions for each analysis stage.

## Included notebooks

- `descriptive_statistics_walkthrough.ipynb`: reproduces Section 4.2.1 descriptive statistics, Table 3(a), Table 3(b), Appendix Tables 8--12, and Figure 2.
- `exploratory_analysis.ipynb`: inspects the canonical dataset, outcome-class distribution, and key modeling variables.
- `modeling_walkthrough.ipynb`: walks through Gate 0, Gate 1, Gate 2, and Axis B models.
- `diagnostics_walkthrough.ipynb`: explains VIF, separation checks, Schoenfeld diagnostic records, and sensitivity checks.
- `qualitative_walkthrough.ipynb`: summarizes directed qualitative analysis and triangulation outputs.
- `reproduction_driver.ipynb`: notebook wrapper around `make reproduce` and `make verify`.

## Canonical vs. explanatory outputs

Notebook outputs may vary slightly by local environment, especially formatting and display metadata. The authoritative reproducible artifacts are the CSV, figure, manifest, and log files regenerated by the scripts under `replication/` and `RQ2_Prompt_Effectiveness_Modeling/analysis/`.


- `robustness_sensitivity_walkthrough.ipynb`: explains the dominant-repository, extreme-PR-size, dominant-language, and PQS-vs-dimension robustness checks generated under `RQ2_Prompt_Effectiveness_Modeling/results/diagnostics/`.

- `illustrative_examples_walkthrough.ipynb`: shows how the paper-referenced qualitative examples are selected from the canonical dataset and exported as evidence artifacts.

The RQ1 notebook is now located at `RQ1_Prompt_Evaluation_Validation/notebooks/rq1_annotation_reliability.ipynb`.

## Appendix B Descriptive Walkthrough

`appendix_b_descriptive_walkthrough.ipynb` reproduces the extended descriptive-analysis layer, including histograms, skewness calculations, outlier summaries, repository/language distributions, and prompt-structure correlations.
