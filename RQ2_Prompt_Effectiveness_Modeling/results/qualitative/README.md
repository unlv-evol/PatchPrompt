# Qualitative Evidence Outputs

This directory contains gate-specific qualitative evidence tables supporting the directed qualitative content analysis used to interpret the Gate 0, Gate 1, and Gate 2 quantitative findings.

The examples were purposefully selected to capture recurring structural patterns across outcome classes, prompt score configurations, technical domains, and integration-depth levels. The goal is not statistical representativeness, but qualitative transparency and interpretive coverage of the mechanisms discussed in the paper.

Gate-specific folders:

- `gate0/`: implementation-oriented versus conceptual-oriented prompts for code generation.
- `gate1/`: evaluability, boundedness, and verification patterns for code adoption.
- `gate2/`: contextual grounding and reuse-depth patterns for integration.

Each gate folder contains CSV, XLSX, PDF, full-record CSV, and README artifacts.
