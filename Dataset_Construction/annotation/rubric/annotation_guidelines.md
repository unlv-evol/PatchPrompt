# Annotation Guidelines

1. Score only the developer's prompt text and refinements in the conversation.
2. Use the PR description and linked metadata only for outcome classification and traceability.
3. Record Context, Specificity, Verification, PQS, outcome class, gate values, and qualitative themes.
4. Preserve adjudication notes for disagreements.
5. Do not include private credentials or non-redistributable source content in public artifacts.
