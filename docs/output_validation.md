# Output Validation

Validation is controlled by `replication/expected_outputs.yaml` and implemented in `replication/verify_outputs.py`.

## Validation modes

Supported validation modes:

- `exists`: artifact must exist;
- `nonempty`: artifact must exist and have nonzero size;
- `csv_schema`: artifact must be a readable CSV and contain the listed required columns.

Generated manifests are written to `RQ2_Prompt_Effectiveness_Modeling/results/manifests/` with artifact paths, byte sizes, and SHA-256 hashes.

## Interpretation

A successful `make verify` confirms that required artifacts exist and conform to expected schemas. It does not assert scientific validity by itself; the scripts and notebooks provide the transparent computation paths used to generate and inspect those outputs.


## Full robustness and sensitivity outputs

The package includes an expanded robustness layer for the stage-based models. These outputs are generated by `RQ2_Prompt_Effectiveness_Modeling/analysis/diagnostics/robustness_sensitivity_outputs.py` and validated by `make verify`. The checks include:

- dominant-repository exclusion, using the most frequent repository within each gate-specific modeling sample;
- extreme pull-request size exclusion, using the 95th percentile PR-size cutoff within each gate-specific modeling sample;
- dominant-language exclusion, using the most frequent programming language within each gate-specific modeling sample;
- aggregate PQS specifications compared against the main individual-dimension models using Context, Specificity, and Verification.

Generated files are written to `RQ2_Prompt_Effectiveness_Modeling/results/diagnostics/`, including `RQ2_Prompt_Effectiveness_Modeling/results/diagnostics/full_robustness_sensitivity_results.csv`, `RQ2_Prompt_Effectiveness_Modeling/results/diagnostics/dominant_repository_exclusion.csv`, `RQ2_Prompt_Effectiveness_Modeling/results/diagnostics/extreme_pr_size_exclusion.csv`, `RQ2_Prompt_Effectiveness_Modeling/results/diagnostics/dominant_language_exclusion.csv`, `RQ2_Prompt_Effectiveness_Modeling/results/diagnostics/pqs_vs_dimension_models.csv`, and `RQ2_Prompt_Effectiveness_Modeling/results/diagnostics/robustness_sensitivity_summary.md`.
