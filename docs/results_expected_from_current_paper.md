## Main RQ2 models

- Gate 0: Context and Specificity predict code generation; Verification is not significant.
- Gate 1: Specificity and Verification predict adoption; Context is positive but not significant.
- Gate 2: Context predicts integration depth; Specificity and Verification are not significant.
- Axis B: prompt structure does not significantly affect merge hazard; Verification is associated with faster close hazard; PR size slows both merge and close hazards.

This file is a human-readable cross-check for artifact evaluators. The machine-readable validation contract is `replication/expected_outputs.yaml`.


## Robustness and sensitivity results

The package now includes the robustness outputs corresponding to the robustness narrative in the paper. The main stage-specific patterns remain qualitatively stable: Context and Specificity remain the strongest predictors of Gate 0 code generation; Specificity and Verification remain the strongest predictors of Gate 1 adoption; Context remains the main positive predictor of Gate 2 integration depth, although its statistical significance weakens when TypeScript cases are excluded because the PA-only sample falls to 57 observations.
